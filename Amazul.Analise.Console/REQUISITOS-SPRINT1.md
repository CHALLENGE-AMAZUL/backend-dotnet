# Advanced Business Development with .NET - Sprint 1

## Objetivo

Desenvolver uma prova de conceito em .NET de uma funcionalidade da solução educativa sobre tecnologia nuclear proposta pelo grupo.

Não é necessário desenvolver o backend completo.

A funcionalidade .NET deve ser diferente ou complementar à desenvolvida em Java.

---

# Entregáveis

## Repositório

- Público no GitHub
- Commits dos integrantes
- .gitignore configurado

## README

Deve conter:

- Grupo
- Integrantes (Nome + RM)
- Descrição resumida da solução
- Escopo da Sprint
- Instruções de execução
- Arquitetura da solução
- Como o .NET se aplica à solução

---

# Aplicação

## Tipo

Aplicação Console .NET

---

## Entidade

Mínimo:

- 1 entidade do domínio

Com:

- atributos coerentes
- validações

---

## Regra de Negócio

Implementar pelo menos:

- 1 regra de negócio

---

## Tratamento de Erros

Implementar:

- try/catch

Sem interromper indevidamente a aplicação.

---

## Operações

Cadastro:

- criar registros

Consulta:

- listar registros
- buscar por critério

Exemplos:

- nome
- código
- categoria

---

## Persistência

Aceito:

- JSON

ou

- Entity Framework Core + Oracle

Os dados devem permanecer após encerrar a aplicação.
