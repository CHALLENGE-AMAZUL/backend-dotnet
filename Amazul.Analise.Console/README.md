## Descrição do projeto - e como se aplica à nossa solução
Um projeto console, que simula uma pré analise em relação ao serviço que temos no Spring Boot. Temos uma plataforma explicativa, com artigos sobre tecnologia nuclear.

Esse projeto em .Net simula a aprovação de propostas sugeridas pela equipe, num fluxo anterior de artigos que seria antes de eles irem a plataforma.
Temos como ideia, implementar um microsserviço que permita inserir arquivos, e eles sejam incluidos automaticamente na plataforma.
